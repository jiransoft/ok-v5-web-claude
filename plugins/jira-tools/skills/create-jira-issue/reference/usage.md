# /create-jira-issue 사용법

`--help` / `-h` 로 호출됐을 때 아래 블록을 그대로 출력하고 종료한다.

```
/create-jira-issue - Jira 이슈 생성

사용법:
  /create-jira-issue                          대화형으로 이슈 생성
  /create-jira-issue 로그인 화면 500 에러 발생  설명을 바탕으로 이슈 생성
  /create-jira-issue --help                   이 도움말 출력

동작:
  1. 컨텍스트 분석 → 이슈 필드 자동 결정
  2. 사용자 확인
  3. Jira 이슈 생성
  4. 결과 출력
```
