# plugins.json 설정 권고 출력 규약

`release-tools` 플러그인의 모든 스킬이 공유한다. 각 스킬의 "plugins.json 설정 권고" 절에서 참조한다.

## 목차

- [언제 출력하는가](#언제-출력하는가)
- [출력 포맷](#출력-포맷)

## 언제 출력하는가

이번 실행에서 `.claude/plugins.json` 에서 찾지 못해 **AskUserQuestion 으로 받은 값이 하나라도
있었다면** 작업 완료 후 아래 블록을 출력한다. 모든 값을 plugins.json 에서 정상 획득했으면 **생략**한다.

무엇을 권고 대상에 넣고 뺄지는 스킬마다 다르다 — 호출된 스킬의 "권고 대상" 목록을 따른다.
공통 원칙은 **질문으로 받은 값만 권고하고, CLI 인자·AI 자동 판단 결과는 제외**한다는 것이다.

## 출력 포맷

실제 질문받은 키만 채워서 출력한다.

````
---
plugins.json 구성 권고

이번 실행에서 아래 값을 `.claude/plugins.json` 에서 찾지 못해 질문으로 받아 진행했습니다.
다음부터 자동으로 처리되려면 `.claude/plugins.json` 에 아래처럼 추가/병합해주세요:

```jsonc
{
  "release-tools": {
    "<key1>": "<획득한 값1>",
    "<key2>": "<획득한 값2>"
  }
}
```

- 파일이 없으면 새로 만드세요
- 이미 있으면 `"release-tools"` 섹션에 **병합**하세요 (덮어쓰지 마세요)
- 토큰/비밀번호 같은 민감 값은 값 자체를 넣지 말고 파일 경로 키(`*File` → `~/.xxx-token`)로 저장하세요
---
````
